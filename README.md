# Plataforma de Asistencia — CEIA Inapewma Coronel

Página estática (HTML + Tailwind + Chart.js) alojada en GitHub Pages. Los datos se guardan en Google Sheets mediante un Web App de Google Apps Script.

- `index.html` — aplicación
- `config.js` — URL del Web App de Apps Script (`API_URL`)
- `logo.js` — insignia institucional embebida

Las credenciales **no** están en este repositorio: se validan en Apps Script.
